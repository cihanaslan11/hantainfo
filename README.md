# HantaInfo 🌍
**Global Hantavirus Outbreak Tracker**

Real-time hantavirus surveillance platform built with vanilla JavaScript, D3.js, and Claude AI API.

🔴 [Live Demo](https://cihanaslan11.github.io/hantainfo)

---

## Features
- 🗺 Interactive world map with real outbreak locations (D3.js + TopoJSON)
- 🔴 Animated sonar-style risk indicators with live case counts
- 🤖 AI-powered chat assistant (Claude API) for real-time Q&A
- 📍 Geolocation support — shows your position on the map
- ⏱ Live clock with automatic timezone detection
- 📰 Curated outbreak news from WHO, CDC, and ECDC
- 📱 Multi-page SPA with smooth transitions

## Data Sources
- [WHO Disease Outbreak News](https://www.who.int/emergencies/disease-outbreak-news)
- [CDC Hantavirus](https://www.cdc.gov/hantavirus)
- [ECDC](https://www.ecdc.europa.eu)
- [NaTHNaC](https://travelhealthpro.org.uk)

## Tech Stack
- Vanilla HTML / CSS / JavaScript
- D3.js v7 — world map rendering
- TopoJSON — geographic data
- Anthropic Claude API — AI assistant
- GitHub Pages — hosting

## Context
Built in response to the May 2026 Andes hantavirus outbreak aboard the MV Hondius cruise ship — 13 cases, 3 deaths, contacts traced across 32 countries.
